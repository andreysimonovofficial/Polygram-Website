Базовая суть

Что такое Polygram

Чистый CAD с коннекторами API и MCP — модульная система, где всё бесшовно подключается. Вход и выход, визуально эргономичный и производит вычисления.

CAD-ядро

Хранит граф, холст и официальные базовые действия. Ванильное ядро не меняется при добавлении расширений.

API + MCP

Мышь, клавиатура и MCP используют один механизм команд. Агент по MCP может создавать и обновлять расширения.

Расширения

Хранятся в отдельных локальных репозиториях. Любые изменения в расширениях никогда не влияют на чистый код CAD.

Задача и решение

Почему нужен Polygram

Статичные диаграммы и фрагментация софта замедляют команды. Polygram превращает визуальную карту в живую систему.

Проблема

Статичность и фрагментация

Обычные диаграммы остаются «просто рисунками», не связанными с реальными процессами и исполнителями.

Команды переключаются между 5–10 сервисами (Miro, Notion, Jira, No-code платформы).

Классические дашборды и ERP копят усталость, а не дают ясность.

Решение

Живая визуальная карта

Пользователь собирает понятную визуальную карту, которая сразу становится реальной системой с агентами и автоматизациями.

Результат — снижение фрагментации, увеличение КПД, полная автоматизация.

Базовые расширения ядра

Core Extensions

Расширения хранятся в отдельных репозиториях и никогда не влияют на чистый код ванильного CAD.

«Секретарь»

Автономный агент коммуникации, который дожимает лиды, назначает встречи и работает через Telegram и почту даже при закрытом браузере.

«Финансы»

Прямая интеграция с эквайрингом и банками — финансовые потоки отображаются на блоках холста в реальном времени.

«Контракты»

Долгосрочные задачи с проверками и автоматическими напоминаниями через Секретаря. Формат CONTRACT.md.
